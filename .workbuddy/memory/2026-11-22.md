# 2026-11-22 col1688 子窗口 JS 注入 / window.external.invoke 回传通道

## 背景
- 目标：子窗口（外部 1688 页）无 `window.ltools`（Wails 不注入外部站），不能用 `Event.Emit`。
- 数据需按条 JSON 从子窗口 JS 回传 Go 端。
- 已弃用 `ExecuteScriptWithResult`（持续 `RESOURCE_NOT_IN_CORRECT_STATE` / `0x800704CF`）与 HTTP 回传（127.0.0.1:48217 被 1688 CSP 拦）。
- 当前通道：Wails 官方 `window.external.invoke`（`chrome.webview.postMessage`）→ Go `RawMessageHandler`。

## 关键决策
- **跨导航注入**：用 `edge.SetExtraInitScripts(...)` → 内部 `embedWebView2` 调 `AddScriptToExecuteOnDocumentCreated`，使每个新文档（含 baxia 验证页）JS 运行前都先执行。
- **脚本必须独立 AddScript 调用，绝不拼接**：60KB 拼接被 WebView2 COM 静默丢弃；bridgeJS 10.9KB 单独成功。

### commit 1bc2ae0 `fix(col1688): embedWebView2 per-script AddScript, fix concatenated overlong drop`
- 改 `third_party/wails/internal/webview2/pkg/edge/chromium.go` `embedWebView2`。
- **Bug**：commit f332b1e 把 bridgeJS + suppliersJS 用 `strings.Builder` 拼成一个 ~47KB 脚本，一次 `e.Init` → `AddScriptToExecuteOnDocumentCreated`。拼接后单脚本超长被 WebView2 COM 静默丢弃，bridgeJS 也没注入（F12 测 `__ltoolsInitErr` 为 null，说明脚本没执行到）。
- **Fix**：改成**逐个** `e.Init`：
  ```go
  e.Init("window.external={invoke:s=>window.chrome.webview.postMessage(s)}")
  if len(ExtraInitScripts) > 0 {
      e.Init("window.__ltoolsInitErr='';")
      for _, s := range ExtraInitScripts {
          wrapped := fmt.Sprintf("(function(){try{%s}catch(e){window.__ltoolsInitErr=(window.__ltoolsInitErr?window.__ltoolsInitErr+';':'')+'s'+':'+String(e)}})()", s)
          e.Init(wrapped)
      }
  }
  ```
  每个脚本独立 `AddScriptToExecuteOnDocumentCreated` 调用，IIFE+try/catch 包裹，错误记 `window.__ltoolsInitErr`。
- bridgeJS(10.9KB) 与 suppliersJS(9KB，非 36KB——之前误记) 各独立注册。
- 诊断日志证实：子窗口 3 个 `AddScript` 全 OK（len=26/11129/9200），suppliersJS 实际 9200 字节，注入成功。

### commit 551c3d4 `col1688: split collectJS into collectJS+navGuardJS (<12KB each); precise window.data.offerV2 path extraction`
**拆分 collectJS（16283B，被 WebView2 静默丢弃）为两个独立脚本**：
- `collectJS`（~3.7KB）：取数 + 自动回传 + c1688:connected 握手。幂等 `__ltoolsCollectInstalled`。

**取数策略改精确路径**（用户提供 1688 搜索结果页结构）：
- 页面：`s.1688.com/selloffer/offer_search.htm`
- 数据：`window.data.offerV2.response.data.OFFER.items[]`
- 每条 item 映射：`name` ← `item.data.shop.text`；`url` ← `item.data.shopAddition.shopLinkUrl`；`level` ← `item.data.bizType`（店铺类型透传）

**编码踩坑**：
- PowerShell 双引号字符串含中文 + 内联反引号 + CRLF 多行 → 解析器乱码 / 转义冲突，反复失败。
